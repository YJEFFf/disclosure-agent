# 공개본 구성

팀 **북적북적**의 미래에셋증권 × 네이버클라우드 AI FESTIVAL 2026 공시 Agent 프로젝트를 개인 포트폴리오용으로 정리한 소스 스냅샷입니다. 팀 공동 작업 결과이며 단독 개발 프로젝트로 표시하지 않습니다. 대회 제출용 원본 저장소는 별도로 비공개(Private) 관리됩니다.

## 원본 비교

2026-11-02에 로컬 프로젝트와 대회 저장소의 추적 파일 518개를 비교했습니다.

| 기준 | 커밋 |
| --- | --- |
| 로컬 작업본 | `761753e8248c545773e194cc6a8fed219203974c` |
| 대회 저장소 | `06ca4e31e617f08c819c79d7510314131c9f01b8` |

- 515개 파일이 동일했습니다. 로컬에만 있는 추적 파일과 미커밋 변경은 없었습니다.
- 차이는 `answerer.py`, 작업일지, 기술제안서 3개 파일에 있었습니다.
- 실행 코드는 로컬본을 바탕으로 가져왔고, `answerer.py`는 대회 저장소의 마지막 수정본을 사용했습니다. 이 버전에는 ‘최대주주’를 최상급 표현으로 오인하지 않는 처리와 근거 없는 URL 제거가 포함됩니다.

## 포함 범위

공시 파서, 검색 인덱스, 질의응답 엔진과 전처리·실행 스크립트는 원본 로직을 유지했습니다. API 상태 점검에서 파일을 읽은 뒤 명시적으로 닫도록 한 곳을 수정하고, `answerer.py`의 줄 끝 공백 하나를 제거했습니다. 공개 안내 문서와 경로 설정의 주석을 정리하고, 대회 데이터 없이 실행할 수 있는 테스트 10개를 추가했습니다.

대회 제공 원문·메타데이터, DB·캐시, 평가 문항·결과, 공유 압축파일, 운영 기록과 비밀 설정은 포함하지 않았습니다. 대회 저장소의 Git 이력도 가져오지 않았습니다. 따라서 이 저장소만으로 대회 데이터 전체에 대한 성능을 재현할 수는 없습니다.

Docker 구성과 의존성 버전은 원본을 유지했습니다. 공개본 검증 범위는 Python 3.12 의존성 설치와 오프라인 테스트이며, 실제 LLM 응답 품질·전체 데이터 전처리·Docker 실행은 이번 공개 과정에서 다시 측정하지 않았습니다.
