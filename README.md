# 공시 Agent

**미래에셋증권 × 네이버클라우드 AI FESTIVAL 2026 · 팀 북적북적**

기업 공시를 검색하고 근거와 함께 자연어 질문에 답하는 HyperCLOVA X 기반 에이전트입니다.

## 주요 내용

- 기업·기간·공시 유형을 구분해 질문에 맞는 문서를 검색합니다.
- 정정 공시와 원본의 관계를 반영해 유효한 근거를 선택합니다.
- 합산·차액·건수 등은 코드로 계산하고, 답변에 공시 근거를 연결합니다.
- 자료 범위를 벗어난 질문과 모호한 질문을 구분해 처리합니다.

```text
질문 → 기업·조건 추출 → 공시 검색 → 코드 계산 → 근거 기반 답변
```

**기술:** Python · HyperCLOVA X · SQLite / FTS5 · 문서 전처리 · 질의응답 API

이 저장소는 공개 프로젝트 소개용입니다. 구현 코드와 대회 제공 자료는 비공개 저장소에서 관리합니다.
